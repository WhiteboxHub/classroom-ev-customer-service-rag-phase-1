# OTA Update 4.2.1 — Customer Release Notes
**For:** EV Owners | **Version:** 4.2.1 | **Size:** 1.2 GB | **Time:** ~20 minutes

## What's New in This Update?

This update improves your charging experience and makes your software update process more reliable.

## Charging Improvements
We've fixed an issue where some vehicles had trouble connecting to DC fast chargers after the previous update. If you experienced error code P1E00 or couldn't start a DC fast charging session, this update resolves that issue.

## Software Update Reliability
We've improved the update download process so it's more reliable on lower-quality WiFi connections. The new update process verifies each chunk of the download before proceeding, preventing partial update failures.

## How to Install
1. Connect to WiFi with good signal strength
2. Go to Settings > Software > Software Update
3. Tap "Download and Install"
4. Your vehicle needs to be in Park with 20%+ charge
5. The update takes about 18-25 minutes
6. Vehicle will restart once during the process — this is normal

## If Your Update Fails
If you see error OTA_INSTALL_FAIL_3:
1. Try connecting to a stronger WiFi network
2. Go to Settings > Software > Retry Update
3. If the issue persists, contact EV Support
